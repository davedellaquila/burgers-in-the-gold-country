# Burgers in the Gold Country

A guide to the Gold Country's burger stops — Highways 49, 88, 4 and 395, Nevada City to Walker.

Public site: https://davedellaquila.github.io/burgers-in-the-gold-country/

This repo hosts the static public copy of the guide (built and maintained as a Muse space; this is its public home so per-place links work for every reader). Each place has its own page — links ride in `?place=<slug>` plus `#/place/<slug>`.
